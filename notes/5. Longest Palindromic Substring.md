## Idea
Since a list of same characters must be a palindrome, so we can skip these characters. Then, we start to search from the left and right of this part of the string. If both `s[left]` and `s[right]` are equal, then the palindrome's length can be extended. Otherwise, stopped.

To save memory usage, stirng slicing is not used, but keeping the starting index of the palindrome and its length.

## Code
My solution:
```python
class Solution(object):
    def longestPalindrome(self, s):
        """
        :type s: str
        :rtype: str
        """
        start = 0
        max_len = 0
        for i in range(len(s)):
            same_ind = 1
            while i < len(s)-1 and s[i] == s[i+1]:
                same_ind += 1
                i += 1
            left, right = i-same_ind+1, i
            while left >= 0 and right < len(s) and s[left] == s[right]:
                curr_len = right-left
                left -= 1
                right += 1
            if curr_len > max_len:
                start = left + 1
                max_len = curr_len
        return s[start:start+max_len+1]
```

## Ideal Solution
Using **Dynamic Programming**. In this problem, it is not specifically efficient than my solution, especially when the `len(s)` is greater. However, the code is very clear and great to learn from.

```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        n = len(s)
        if n < 2:
            return s

        # dp[i][j]: whether s[i:j+1] is a palindrome
        dp = [[False] * n for _ in range(n)]
        
        # Every substring with length of 1 is a palindrome
        for i in range(n):
            dp[i][i] = True

        # start & length of longest palindrome
        start = 0
        max_len = 1

        # Walk through the string from right bottom to left top to make sure dp[i+1][j-1] is checked before dp[i][j]
        for j in range(1, n):
            for i in range(j):
                if s[i] == s[j]:
                    if j - i == 1 or dp[i+1][j-1]:
                        dp[i][j] = True
                        cur_len = j - i + 1
                        if cur_len > max_len:
                            max_len = cur_len
                            start = i

        return s[start:start + max_len]
```
