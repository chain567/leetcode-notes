## Idea
I used recursion to solve this problem. When current `number` is greater than the curernt `coins` we are at, there can be two possibilities: one is `helper(number-coins[i], i) + helper(number, i+1)`, the other is `helper(number, i+1)`. 

**Warning**: not to use `result += helper(number-coins[i], i) + helper(number, i+1)`, because `result` will not be used in the following code.

## Code
```python
class Solution:
    def change(self, amount: int, coins: List[int]) -> int:
        n = len(coins)
        lib = {}
        def helper(number: int, i: int) -> int:
            if number == 0:
                return 1
            if i == n and number > 0:
                return 0
            if (i, number)in lib:
                return lib[(i, number)]

            if number >= coins[i]:
                res = helper(number-coins[i], i) + helper(number, i+1)
            else:
                res = helper(number, i+1)
            lib[(i, number)] = res
            return res

        return helper(amount, 0)
```

## Ideal Solution
This solution is the ideal one. It uses an array to manage all the number of previous paths, and then added-to the final `amount`. 

The first for-loop `coin` means the coin that is open to use. So it starts from the smallest coin, and then added to the next `coin` index(using i-coin here to make the management clearer). If the `amount` cannot be reached by combination of `coins`, then `result[amount]` will be `0`(the cursor cannot reach `amount`).

```python
class Solution:
    def change(self, amount: int, coins: List[int]) -> int:
        n = len(coins)
        result = [0] * (amount+1)
        result[0] = 1
        for coin in coins:
            for i in range(coin, amount + 1):
                result[i] += result[i-coin]
        return result[amount]
```
