## Idea
Basic sliding window problem. Move the `left` until the `curr` value is smaller than `k`, and then add the # of subarrays with fixed `right` end into the `result`. -> therefore, with a fixed `right` index, the subwarray inside can be from `left` to `right`, which is just `right - left + 1`.

**Time complexity: $\theta(n)$; Space Complexity: $\theta(1)$**

## Code
```python
class Solution(object):
    def numSubarrayProductLessThanK(self, nums, k):
        """
        :type nums: List[int]
        :type k: int
        :rtype: int
        """
        left, right = 0, 0
        n = len(nums)
        curr = nums[left]
        result = 0
        while right < n:
            while left <= right and curr >= k:
                curr /= nums[left]
                left += 1
            result += right - left + 1
            right += 1
            if right == n:
                break
            curr *= nums[right]
        return result
```

## Ideal Solution
My solution is just the ideal one. Better than brute force.

**Time complexity: $\theta(n^2)$; Space Complexity: $\theta(1)$**

```python
class Solution:
    def numSubarrayProductLessThanK(self, nums: List[int], k: int) -> int:
        n = len(nums)
        ans = 0

        for i in range(n):
            product = 1

            for j in range(i, n):
                product *= nums[j]

                if product < k:
                    ans += 1
                else:
                    break

        return ans
```
