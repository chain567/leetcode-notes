## Idea
First, check if the nums is perfectly sorted. If it is sorted, return the reversed string.
If not, then find the digits that is not in the 'descending'. This marks that this digit need to be swapped with the closest digits(`closest > tar`) behind it.
After find and swap the two digits, the remaining part is sorted.

## Code
My solution:
```python
class Solution(object):
    def nextPermutation(self, nums):
        """
        :type nums: List[int]
        :rtype: None Do not return anything, modify nums in-place instead.
        """
        sort = True
        for i in range(len(nums)-1):
            if nums[i] < nums[i+1]:
                sort = False
        if sort:
            nums[:] = nums[::-1]
            return
        h = len(nums)-1
        # find digits to swap
        while nums[h] <= nums[h-1]:
            h -= 1
        h -= 1
        change = nums[h:]
        tar = change[0]
        closest = 1
        for dig in range(2, len(change)):
            if change[dig] < change[closest] and change[dig] > tar:
                closest = dig
        temp = change[closest]
        change[closest] = tar
        change[0] = temp
        # change[closest], change[0] = change[0], change[closest]

        change = [change[0]] + sorted(change[1:])
        nums[:] = nums[:h] + change
```

## Ideal Solution
The perfect solution uses a similar step except for the last part.

First, we both check if the nums is in descending order, and the return a reversed nums if so.
However, the perfect answer reused the result, and find the last position for the `ascending` position. This is more efficient than mine, as I search for it again from the last digit.

After that, the answer find the `closest` as well. Since the searched part is in "descending", the last part is still in descending order as well. So only a simple reverse is enough, instead of a `sorted` function.

```python
def nextPermutation(self, nums):
    i = j = len(nums)-1
    while i > 0 and nums[i-1] >= nums[i]:
        i -= 1
    if i == 0:   # nums are in descending order
        nums.reverse()
        return 
    k = i - 1    # find the last "descending" position
    while nums[j] <= nums[k]:
        j -= 1
    nums[k], nums[j] = nums[j], nums[k]  
    l, r = k+1, len(nums)-1  # reverse the second part
    while l < r:
        nums[l], nums[r] = nums[r], nums[l]
        l +=1 ; r -= 1
```
