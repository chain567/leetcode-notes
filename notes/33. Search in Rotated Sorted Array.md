## Idea
This problem practices ideas of **binary search**. I was once very confused about how to move the cursor.
Since binary search is only useful for sorted array, the idea is to think of 1. which subarray is in ascending order 2. is `target` in the range?

Since the array is `rotated`, if the left subarray is not sorted, then its the right one. I was stuck here btw.

**Time complexity: $\theta(log(n))$; Space Complexity: $\theta(1)$**

## Code
```python
class Solution:
    def search(self, nums: List[int], target: int) -> int:
        left, right = 0, len(nums)-1
        while left <= right:
            mid = (left + right) // 2
            if nums[left] <= nums[mid]:
                if target >= nums[left] and target <= nums[mid]:
                    if nums[mid] == target:
                        return mid
                    elif nums[mid] < target:
                        left = mid + 1
                    else:
                        right = mid - 1
                else:
                    left = mid + 1
            else:
                if target >= nums[mid] and target <= nums[right]:
                    if nums[mid] == target:
                        return mid
                    elif nums[mid] < target:
                        left = mid + 1
                    else:
                        right = mid - 1
                else:
                    right = mid - 1
        return -1
```

## Ideal Solution
This solution used `bisect` library. 
It gets the rotated point of the array, and then use binary search to get the value.
`rot` gets the position, and `real` navigates to the real index in the array. `rot` is just the constant that marks the shift of array.
This solution looks simple and is hard to make mistakes to use this solution.

**Time complexity: $\theta(log(n))$; Space Complexity: $\theta(1)$**

```python
class Solution:
    def search(self, nums: List[int], target: int) -> int:
        n = len(nums)
        rot = bisect_left(nums, True, key=lambda n: n <= nums[-1])
        
        lo, hi = 0, n - 1

        while lo <= hi:
            mid = (lo + hi) // 2
            real = (mid + rot) % n

            if nums[real] == target:
                return real
                
            if nums[real] < target:
                lo = mid + 1
            else:
                hi = mid - 1

        return -1
```
