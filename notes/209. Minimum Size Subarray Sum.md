## Idea
This is a simple sliding window problem. However, I was stucked for minutes when thinking of how to stop the `while` loop, though I thought a single `for` loop or `while` loop are not able to solve the question. 

Since the problem requires a **continous subarray**, I found the logic: use a `for` loop outside while keep a `while` loop inside to shrink the width of the whindow. 

## Code
My solution:

Solution 1: $\theta(n)$ #Sliding-Window
```python
class Solution(object):
    def minSubArrayLen(self, target, nums):
        """
        :type target: int
        :type nums: List[int]
        :rtype: int
        """
        low = 0
        min_len = float("inf")
        curr = 0
        for i in range(len(nums)):
            curr += nums[i]
            while curr >= target:
                if i - low + 1 < min_len:
                    min_len = i - low + 1
                curr -= nums[low]
                low += 1
        return 0 if min_len == float("inf") else min_len
```

Solution 2: $\theta(nlog(n))$ #Binary-Search& #Pref_lst
```python
class Solution(object):
    def minSubArrayLen(self, target, nums):
        """
        :type target: int
        :type nums: List[int]
        :rtype: int
        """
        def find_last_val(arr, high, val):
            low = 0
            mid = (low + high) // 2
            closest = -1
            while low <= high:
                mid = (low + high) // 2
                if arr[mid] > val:
                    high = mid - 1
                else:
                    if mid > closest:
                        closest = mid
                    low = mid + 1
            return closest
        n = len(nums)
        ans = float("inf")
        pref_lst = [0] * (n+1)
        for i in range(n):
            pref_lst[i+1] = pref_lst[i] + nums[i]

        for j in range(1, n+1):
            rem = pref_lst[j] - target
            check = find_last_val(pref_lst, j-1, rem)
            if check != -1:
                ans = min(ans, j - check)
        return 0 if ans == float("inf") else ans
```

## Ideal Solution
Those two solutions are the two approaches to this question. 
1. The first solution is #sliding-window, which is efficient and takes less memory. However, this is because there are only positive numebrs in this array. 
2. If not, then only the second solution, which is the #pref-list solution can be used. This uses a function that use **binary search** to search for the largest val that is close to the target value. Every index in `pref_lst` sums all the numbers before that itself. So the idea is `target <= pref_lst[j] - pre_lst[i]`, and it comes to `pre_lst[i] <= pref_lst[j] - target`.
