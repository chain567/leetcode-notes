## Ideal Solution
This uses two-pointer. $\theta(1)$ runtime and $\theta(1)$ memory usage.
```python
# Definition for singly-linked list.
# class ListNode(object):
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def removeNthFromEnd(self, head, n):
        dummy = ListNode(0, head)
        fast = slow = dummy
        # since there is a new dummy node, move n+1 steps
        for _ in range(n + 1):
            fast = fast.next
        # move together, so when fast reach the end, slow is just n steps before the last
        while fast:
            fast = fast.next
            slow = slow.next
        # delete the next node of slow
        slow.next = slow.next.next
        return dummy.next
```
