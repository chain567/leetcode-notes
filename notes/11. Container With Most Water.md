## Idea
Check the greatest area that can be formed in both lines. First I think about optimizing my first solution, which is a $\theta(n^2)$ solution.

In #2, I add a justification: if the line is descending, then refuse to check, and this justification is used for both `left` and `right`.

However, to the end, it is still $\theta(n^2)$ time complexity. To optimize it, a **two pointer** solution must be used.

Think of every `height` column. Its maximum is the largest and furthest. since the height of the block is determiend by the shortest column between `left` and `right`, so as **the column has its maximum height for this column (the block is already at the (`left` or `right` columns height) with the furthest width**-- For example, `[1, 1000, 9, 8]`, when `1` is used as left and `8` is used as right, the height is already 1, which is the highest using `1` and the furthest width `len(height)`, a block cannot be larger using `1`. So `1` need to be moved inward.

## Code Process
My #1 solution:
```python
class Solution(object):
    def maxArea(self, height):
        """
        :type height: List[int]
        :rtype: int
        """
        max_vol = 0
        for i in range(len(height)):
            left = height[i]
            for j in range(i, len(height)):
                right = height[j]
                curr_vol = min(left, right) * (j-i)
                if curr_vol > max_vol:
                    max_vol = curr_vol 
        return max_vol
```

Final Solution:
```python
class Solution(object):
    def maxArea(self, height):
        """
        :type height: List[int]
        :rtype: int
        """
        left = 0
        right = len(height) - 1
        max_vol = 0

        while left < right:
            curr_vol = min(height[left], height[right]) * (right - left)
            if curr_vol > max_vol:
                max_vol = curr_vol
            if height[left] < height[right]:
                left += 1
            else:
                right -= 1

        return max_vol   
```

## Ideal Solution
**Same idea** as My Final Solution.

```python
class Solution:
    def maxArea(self, height: list[int]) -> int:
        i = 0
        j = len(height) - 1
        res = 0

        while i < j:
            res = max(res, (j - i) * min(height[i], height[j]))
            if height[i] < height[j]:
                i += 1
            else:
                j -= 1

        return res

```
