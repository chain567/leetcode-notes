## Idea
This is a recursion solution. The idea is very simple: use `helper` function to enumerate all the branches. The base case is when `left` and `right` are both equals to 0. In this case, append the `ans` to `res`, and then return this branch. 
For `left`, the idea is simple: only append `(` if there remains # of `left`. Then the function `helper` is called, which goes to one branch;
Consider another branch: For `right`, the idea is different: only append `)` if # of `right` is greater than `left`, then there is another branch: we can start to put `)`.

Therefore, the two seperate `if` statements go through all the branches.

## Code
```python
class Solution(object):
    def generateParenthesis(self, n):
        """
        :type n: int
        :rtype: List[str]
        """
        res = []
        def helper(left, right, ans):
            if left == 0 and right == 0:
                res.append(ans)
                return
            else:
                if left > 0:
                    helper(left-1, right, ans+"(")
                if right > left:
                    helper(left, right-1, ans+")")
        helper(n, n, "")
        return res
```
