## Idea
nums = [2, 3, 1, 0, 4] 
Get the answer in $O(n)$ by #Greedy -> Local Optimization

Understand this question as a car moving:
start from 0, and then go through the list. In each step, check gas = max(gas-1, nums[i]); if gas becomes 0, return false(the car cannot move forward)

if the car can go through, then return true



## Code
My solution:
```python
class Solution:
    def canJump(self, nums: list[int]) -> bool:
        gas = nums[0]
        for i in range(1, len(nums)):
            if gas == 0:
                return False
            gas = max(gas-1, nums[i])
        return True
```
