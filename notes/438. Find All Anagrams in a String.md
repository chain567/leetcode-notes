## Idea
This solution is to use two library to keep record of the character frequency in `p` and in current string. If the sliding window matches with the library, then it is `True`, return the `start` index. If the window is shorter than `len(p)`, then increase the length of window; if longer, then move the `start` index forward, update the character frequency in `curr`, and then check if it matches.

## Code
```python
class Solution(object):
    def findAnagrams(self, s, p):
        """
        :type s: str
        :type p: str
        :rtype: List[int]
        """
        lib = {}
        curr = {}
        n = len(s)
        t = len(p)
        start = 0
        result = []
        for cha in p:
            if cha not in lib:
                lib[cha] = 1
            else:
                lib[cha] += 1
        for i in range(n):
            if s[i] not in curr:
                curr[s[i]] = 1
            else:
                curr[s[i]] += 1
            if i - start + 1 > t:
                curr[s[start]] -= 1
                if curr[s[start]] == 0:
                    del curr[s[start]]
                start += 1
            if i - start + 1 == t:
                same = True
                for key, val in curr.items():
                    if key not in lib or val != lib[key]:
                        same = False
                if same:
                    result.append(start)
        return result
```

## Ideal Solution
Since there are only English uppercase characters, only a 26-length array is needed: to access the frequncy of one character, use `a[ord(p[i]-97)]`. Move the sliding window for `n2` steps, then start to slide the window instead of checking the length(because the window length == `len(p)`). Otherwise similar.

```python
class Solution:
    def findAnagrams(self, s: str, p: str):
        n1, n2 = len(s), len(p)
        if n1 < n2:
            return []

        a = [0] * 26
        b = [0] * 26
        res = []

        for i in range(n2):
            a[ord(p[i]) - 97] += 1
            b[ord(s[i]) - 97] += 1

        if a == b:
            res.append(0)

        for i in range(n2, n1):
            b[ord(s[i]) - 97] += 1
            b[ord(s[i - n2]) - 97] -= 1

            if a == b:
                res.append(i - n2 + 1)

        return res
```
