## Idea
Idea is that the window will goes from left to right, and search if there is different characters that need to be replaced. 
Since the replacement is not limited, the minimized times of replacement is to find the `max_freq` of the character existence in the window, and then calculate if `k` times of replacement can replace those different characters.

In short, find most frequence character, then replace other characters. If `k` times is not enough, stop and move the slide window.

## Code
My First Solution:
Correct, but $\theta(n^2)$
```python
class Solution(object):
    def characterReplacement(self, s, k):
        """
        :type s: str
        :type k: int
        :rtype: int
        """
        n = len(s)
        longest = 0
        for i in range(n):
            curr = i
            lib = {}
            exist = []
            max_freq = 0
            while curr < n:
                if s[curr] not in lib:
                    lib[s[curr]] = 1
                    exist.append(s[curr])
                else:
                    lib[s[curr]] += 1
                for cha in exist:
                    max_freq = max(max_freq, lib[cha])
                if curr-i-max_freq+1 > k:
                    break
                longest = max(longest, curr-i+1)
                curr += 1
        return longest
```

## Ideal Solution
This is a better solution, editted from my previous solution. This time, it is $\theta(n)$.

The core idea is the same, but the logic is more efficient: reuse the calculations in the previous calculation, only update the `lib` if the window moves.

Therefore, we do not have to process `k` times for every `curr`, which save a lot of time.
```python
class Solution(object):
    def characterReplacement(self, s, k):
        """
        :type s: str
        :type k: int
        :rtype: int
        """
        n = len(s)
        longest = 0
        start = 0
        lib = {}
        max_freq = 0
        for curr in range(n):
            if s[curr] not in lib:
                lib[s[curr]] = 1
            else:
                lib[s[curr]] += 1
            max_freq = max(max_freq, lib[s[curr]])
            if curr-start-max_freq+1 > k:
                lib[s[start]] -= 1
                start += 1
            longest = max(longest, curr-start+1)
        return longest
```
