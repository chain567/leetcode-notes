## Idea
Can be solved either by #heap or #greedy. Here solved by #greedy

### Example
tasks = [A, A, B, B, C], n = 2
solution: A -> B -> C -> A -> B -> IDLE -> A

**Idea: The highest frequency tasks should be done at first.**
So start with top = 3(frequency of `A`):
    A _ _ | A _ _ | A  -> Call it as a *Frame*
frame length: (n+1) * (top-1)

ties = 2 (`A` and `B` are tied)
    A B _ | A B _ | A B
            **last interval**: how many elements that **have tied frequency**

### If we have more elements:
tasks = [A, A, B, B, C, C, D]
if frame < len(tasks):
    whatever left **can be added after the end of the frame.**

so return max(frame, len(tasks))

## Code
My solution:
```python
class Solution:
    def leastInterval(self, tasks: list[str], n: int) -> int:
        counts = Counter(tasks).values()
        top = max(counts)
        ties = sum(1 for c in counts if c == top)
        frame = (top - 1) * (n + 1) + ties

        return max(frame, len(tasks))
```
