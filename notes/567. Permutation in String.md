## Idea
I used a pointer to keep track of the slide of the window. `curr` manages the existence of characters in the current window, and `target` manages the existence of characters in the target string.

**Time complexity: $\theta(n)$; Space Complexity: $\theta(n)$**

## Code
```python
class Solution(object):
    def checkInclusion(self, s1, s2):
        """
        :type s1: str
        :type s2: str
        :rtype: bool
        """
        m, n = len(s1), len(s2)
        if m > n:
            return False
        target = {}
        for s in s1:
            if s not in target:
                target[s] = 1
            else:
                target[s] += 1
        curr = {}
        for i in range(0, m):
            add = s2[i]
            if add not in curr:
                curr[add] = 1
            else:
                curr[add] += 1
        for idx in range(m, n+1):
            if curr == target:
                return True
            if idx < n:
                curr_s = s2[idx]
                curr[s2[idx-m]] -= 1
                if curr[s2[idx-m]] == 0:
                    del curr[s2[idx-m]]
                if curr_s in curr:
                    curr[curr_s] += 1
                else:
                    curr[curr_s] = 1
                
        return False
```

## Ideal Solution
Since we are only required to check if the time of existence of all characters matches with the target string's, `matches` can be used to keep record of this. `matches` calculates the # of characters that exists for the same time.

Use the first loop to build the sliding window. Then started to **add & remove** characters from the window.

1. **add**: If the # of the current character was equal to the # in target, and another one is going to be added to the window, then `matches -= 1` since it is not matched; If the # of the current character was **1** less than the # in target, and another one is going to be added to the window, then `matches += 1` since it is now matched.

2. **remove**: If the # of the current character was equal to the # in target, and it is going to be removed out of the window, then `matches -= 1` since it is not matched; If the # of the current character was **1** more than the # in target, and it is going to be removed out of the window, then `matches += 1` since it is now matched.

**Time complexity: $\theta(n)$; Space Complexity: $\theta(1)$**

(`c1` and `c2` are $\theta(1)$ since they take constant space.)

```python
class Solution(object):
    def checkInclusion(self, s1, s2):
        m, n = len(s1), len(s2)
        if m > n:
            return False

        c1 = [0] * 26
        c2 = [0] * 26

        for i in range(m):
            c1[ord(s1[i]) - ord('a')] += 1
            c2[ord(s2[i]) - ord('a')] += 1

        # Use a variable to manage the existence of character
        matches = 0
        for i in range(26):
            if c1[i] == c2[i]:
                matches += 1

        for i in range(m, n):
            if matches == 26:
                return True

            # --- 1. Add Character ---
            r_idx = ord(s2[i]) - ord('a')
            c2[r_idx] += 1
            if c1[r_idx] == c2[r_idx]:
                matches += 1
            elif c1[r_idx] + 1 == c2[r_idx]:  # Update 'matches' status
                matches -= 1

            # --- 2. Remove Character ---
            l_idx = ord(s2[i - m]) - ord('a')
            c2[l_idx] -= 1
            if c1[l_idx] == c2[l_idx]:
                matches += 1
            elif c1[l_idx] - 1 == c2[l_idx]:  # Update 'matches' status
                matches -= 1

        return matches == 26
```
