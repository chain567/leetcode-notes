## Idea
To make an array with three empty arrays inside it, only `lib = [[] for _ in range(numRows)]` can be used. 
Notice that the sequence is simple: one round of `numRows`, and then an inverse sequence of `numRows - 2`. 
Use `lib` to store the string `s` in these results and use `join` to return the result.

**Time complexity: $\theta(n)$; Space Complexity: $\theta(n)$**

## Code
```python
class Solution(object):
    def convert(self, s, numRows):
        """
        :type s: str
        :type numRows: int
        :rtype: str
        """
        n = len(s)
        lib = [[] for _ in range(numRows)]
        inverse = False
        i = 0
        while i < n:
            if not inverse:
                for j in range(numRows):
                    if i == n:
                        break
                    lib[j].append(s[i])
                    i += 1
                inverse = True
            else:
                for k in range(numRows-2, 0, -1):
                    if i == n:
                        break
                    lib[k].append(s[i])
                    i += 1
                inverse = False
        result = ""
        for arr in lib:
            arr_str = "".join(arr)
            result += arr_str
        return result
```

## Ideal Solution
This solution is to minimize the space complexity. It uses `a` only to manage the result. 
`i` for-loop is used to navigate to the required line, and `j` means the current index. `j` is chosed for every `2*(numRows-1)` index, which is the start of the next repeating(`numRows` downward, `numRows-2` upwards, `2*(numRows-1)` in total).
So the solution just add a pure `i=0` and `i = numRows-1` row, and then for the middle rows, they are adding every `2*(numRows-1)` number, as well as the middle parts: in every cycle the `i` & `numRows-i` number appears for twice. So there is another append in the string. This is a pure mathematical sequence, so take a look at the cycle of `0-5`, and for Row2: 2 and 4 -> 2 is the normal downward number, and 4 is calculated **2** index upward and **2** index left-downward from 8, which is the next Row 2 number

```
Row 0:  0        6          12          18
Row 1:  1     5  7      11  13      17  19
Row 2:  2  4     8  10      14  16      20
Row 3:  3        9          15          21
```

**Time complexity: $\theta(n)$; Space Complexity: $\theta(n)$**

```python
class Solution:
    def convert(self, s: str, numRows: int) -> str:
        if numRows == 1: return s
        a=""
        for i in range(numRows):
            for j in range(i,len(s),2*(numRows-1)):
                a+=s[j]
                if(i>0 and i<numRows-1 and j+2*(numRows-1)-2*i < len(s)):
                    a+=s[j+2*(numRows-1)-2*i]
        return a
```
