## Idea
Similar idea with 3Sum.

Note: remember not to use `nums` instead of `new_nums` when updating the value of `curr`.

## Code
My solution:
```python
class Solution(object):
    def threeSumClosest(self, nums, target):
        """
        :type nums: List[int]
        :type target: int
        :rtype: int
        """
        closest = nums[0] + nums[1] + nums[2]
        new_nums = sorted(nums)
        for i in range(len(new_nums)):
            j = i + 1
            k = len(new_nums) - 1
            while j < k:
                curr = new_nums[i] + new_nums[j] + new_nums[k]
                if abs(curr-target) < abs(closest-target):
                    closest = curr
                if curr > target:
                    k -= 1
                elif curr < target:
                    j += 1
                else:
                    return curr
        return closest
```

## Ideal Solution
Same strategy as well, but some parts can be optimized.

```python
class Solution(object):
    def threeSumClosest(self, nums, target):
        nums.sort()
        n = len(nums)
        # Initialization
        closest = nums[0] + nums[1] + nums[2]
        best_diff = abs(closest - target)
        
        for i in range(n - 2):
            # If nums[i] is the same, then only do it once.
            if i > 0 and nums[i] == nums[i-1]:
                continue
            
            j, k = i + 1, n - 1
            while j < k:
                curr = nums[i] + nums[j] + nums[k]
                diff = curr - target
                
                # If curr == target, then return.(I have this in my own solution)
                if diff == 0:
                    return curr
                
                # Only do the abs() once, and then call the value when used
                if abs(diff) < best_diff:
                    best_diff = abs(diff)
                    closest = curr
                
                if diff > 0:
                    k -= 1
                    # if the element is the same, then do not do it again
                    while j < k and nums[k] == nums[k+1]:
                        k -= 1
                else:
                    j += 1
                    # if the element is the same, then do not do it again
                    while j < k and nums[j] == nums[j-1]:
                        j += 1
                        
        return closest
```
