## Idea
This code is $\theta (n)$. The code has a sliding window that swipes through all the consecutive substrings. Then, use $count += \frac{(length-1) * (length-2)}{2}$ to calculate the number of consecutives (length 3: 1, length4: 3, length 5: 6...).

## Code
My solution:
```python
class Solution(object):
    def numberOfArithmeticSlices(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        if len(nums) < 3:
            return 0
        n = len(nums)
        count = 0
        left, right = 0, 1
        while right < n-1:
            if nums[right+1]-nums[right] == nums[right]-nums[right-1]:
                right += 1
            else:
                length = right - left + 1
                count += (length-1) * (length-2)/2
                if right < n - 1:
                    left = right
                right += 1
                
        length = right - left + 1
        count += (length-1) * (length-2)/2
        return count
```

## Other Solution
1. Check if the array has fewer than 3 elements — return 0.
2. Compute a difference array `d` of length `n - 1`.
3. Group consecutive same differences using `groupby`.
4. For each group of size ≥ 2, count slices using `k * (k - 1) / 2`.

This solution takes $\theta(n)$ memory than my solution. However, this code is clear and simple. `groupby` function is useful in spliting an array. Then it goes to the same idea as mine `r += k * (k - 1) // 2`.
```python
class Solution(object):
    def numberOfArithmeticSlices(self, nums):
        from itertools import groupby

        if len(nums) < 3:
            return 0

        d = [nums[i + 1] - nums[i] for i in range(len(nums) - 1)]
        r = 0

        for _, g in groupby(d):
            k = len(list(g))
            r += k * (k - 1) // 2

        return r
```
